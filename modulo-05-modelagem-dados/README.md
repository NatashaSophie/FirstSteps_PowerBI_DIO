# Módulo 05 — Modelagem de Dados com Power BI

> [Voltar ao repositório da Formação Power BI Analyst](../README.md)

Este módulo reúne os desafios de modelagem de dados desenvolvidos durante a Formação Power BI Analyst da DIO.

## Desafios

| Desafio | Projeto | Situação |
|---|---|---|
| [01](desafio-01-star-schema-universidade/) | Star Schema da Universidade — análise centrada no Professor | Concluído |
| [02](desafio-02-modelagem-transformacao-dax/) | Modelagem e Transformação de Dados com DAX — Financial Sample | Concluído |

O **Desafio 01** contém o modelo dimensional editável em DBML, o script SQL para MySQL, um diagrama vetorial e documentação das escolhas, da granularidade e das hipóteses temporais.

O **Desafio 02** desenvolve a transformação da base Financial Sample no Power Query, a criação de tabelas relacionadas, uma dimensão calendário e medidas DAX, além de uma página de validação de vendas e lucro. Sua documentação técnica, incluindo as decisões e limitações da modelagem, está disponível no [README do Desafio 02](desafio-02-modelagem-transformacao-dax/README.md).
